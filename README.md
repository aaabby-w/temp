# Fantasy Ring Map Template

独立的 Three.js 环形幻想地图模板。根据项目所有者提供的 **8192 × 1900** 参考图，重建独立 SVG 色块、共用边界和圆柱上的三角几何。运行时地图不再读取 JPG 纹理，也不再从颜色提取高度、透明度或凹凸。浅色模式采用每个分区内部采样的原色；深色模式降低亮度并调整线条对比。

原图两端已增加一段 **1024 × 1900** 的矢量海岸延展，总画布为 **9216 × 1900**。原有区域与节点坐标不移动；两侧截断的陆地自然收尾，以海峡过渡并闭合环绕接缝。新增部分是 AI 助手编写的矢量补绘，不属于原作已有设定，详见 [接缝说明](docs/seam-extension.md)。

**想自己删岛、补岛或改边界？从 [地图人工校对教程](docs/地图人工校对教程.md) 开始。**

## 矢量版与校对

- 母版包含 138 个路径对象，含补绘后导出为 140 个独立面、29,496 个填色三角形；边界描线另计。这些面包括封闭浅色水域／小岛轮廓，不代表行政区域数量。
- 同一条分界由邻接色块共用，统一简化、平滑后再三角化。生成检查要求整个分区无空洞、无重叠。
- 圆柱填色按窄经度条带切分，避免大三角形穿过圆柱内部造成裂缝。
- 浏览 `http://localhost:5174/vector-review.html`（端口按开发服务器实际输出调整），可以滑动对比原图与 SVG、放大到 400%、点击色块查看编号。
- **编辑母版为 `art-source/atlas-editable.svg`**。保存后执行 `pnpm atlas:build`，会同步生成 `public/assets/atlas.svg` 与运行时几何 `atlas-regions.json`，并重新计算描边。
- 在地图网址后加 `?view=seam` 可以直接查看补绘海峡。

这是从 JPEG 自动重建的可校对稿，不是原始矢量文件的无损还原。细小岛屿、没有可靠内部采样点的狭长区域，以及近乎同色的弱边界可能被简化或误判；需要逐区人工确认。`docs/vectorization-report.json` 的分区一致率仅衡量简化前后，不代表地理识别准确率。

### 手工修改后的同步（仅制图时需要）

正常启动网站不需要 Python。首次编辑地图时，需要 Python 3.11+；安装一次离线制图依赖：

```bash
pnpm atlas:setup
```

之后每次用 Inkscape 编辑并保存 `art-source/atlas-editable.svg`，运行：

```bash
pnpm atlas:build
pnpm build
```

同步支持闭合曲线路径、内孔、对象移动和缩放；会拒绝自交、重叠和不匹配的环绕接缝。`pnpm atlas:test` 在临时目录测试删岛、新增曲线和错误处理，不会改动母版。完整操作与撤回方法见上面的教程。

`scripts/vectorize-atlas.py` 仅保留用于重新追踪 JPG，结果输出到 `art-source/traced/`，不是日常同步命令。不要用重新追踪覆盖人工校对成果。原始 JPG 始终只读保留。

## 本地运行

地图首次打开与 `RESET`／「返回总览」使用默认视角 FOV 71，ZOOM 100% 对应此默认视角，缩放范围为 FOV 28–78。手机端详情默认收起，点「展开档案」阅读，地点导航可横向滑动。

中文使用随站点发布的 **Noto Serif SC 400**（SIL Open Font License 1.1），标题、地点名称和档案正文共享同一中文字体；英文 UI 保留无衬线字体。Fontsource 的 Unicode 分片按当前文字下载，构建只输出 WOFF2，`font-display: swap` 避免等待字体时文字不可见。许可随部署保存在 `licenses/noto-serif-sc-OFL.txt`。更新依赖时应保留分片和授权文件。

```bash
pnpm install
pnpm dev
```

如果 `node_modules` 已经存在，不需要重复安装，直接运行 `pnpm dev`。生产构建使用：

```bash
pnpm build
```

`vite.config.ts` 使用相对路径，构建产物可以放在任意 GitHub Pages 子路径。

## 操作

- 鼠标或单指左右拖动：环向移动
- 触控板横向或纵向滑动：均转换为环向移动，不再上下移动地图
- `⌘/Ctrl + 滚轮` 或双指捏合：缩放
- `←` / `→`：环向移动；`+` / `-`：缩放；`0` / `Home`：复位
- 点击任意节点：镜头转向并打开节点面板
- 双击地图：以点击位置为中心平滑放大；再次双击返回总览

节点会在靠近时显示跟随光标的坐标提示，选中后绘制到档案面板的引导线，并按“编号 → 名称 → 坐标 → 正文”的顺序解锁内容。底部状态栏会实时显示光标对应的地图坐标。开启系统“减少动态效果”时，循环扫描与过渡会停用。

地图色块和描线均为几何，无需 8192px 纹理支持。缩放范围为 28°–78° 视场角，像素比上限为 2。矢量避免纹理像素块，但最终清晰度仍取决于屏幕分辨率，曲线精度也受轮廓简化容差影响。

## 人工添加节点（推荐）

你不必再依赖自动识别。页面里已经内置节点编辑器：

1. 启动本地页面。
2. 点击页面右下角的 `NODE EDITOR`。也可以直接在网址末尾添加 `?editNodes=1`。
3. 移动鼠标，左下角会显示当前地图坐标。
4. 在需要添加节点的位置单击。页面会把一整行节点代码复制到剪贴板，并短暂显示“已复制”。
5. 打开 `src/nodes.ts`，找到 `const manual: AtlasNode[] = [`。
6. 把复制的代码粘贴到数组中。例如：

```ts
const manual: AtlasNode[] = [
  { code: "U60", name: "未命名节点 60", kind: "unnamed", x: 4096, y: 950, note: "等待补充档案。" },
];
```

7. 保存文件，Vite 会自动刷新页面。需要继续添加时，请手动把后续 `code` 和名称改成 `U61`、`U62`……，避免重复编号。

如果要添加新的正式地点，把 `kind` 改成 `"named"`，并填写名称和说明：

```ts
{ code: "08", name: "新地点", kind: "named", x: 4096, y: 950, note: "这里写地点档案。" },
```

节点的 `x` 范围是 `0–9216`，`y` 范围是 `0–1900`。编辑器通过 Three.js 射线拾取读取弯曲地图表面的 UV，所以即使当前地图已经旋转，复制出来的仍然是正确的地图坐标。修改旧自动识别节点时，请看教程中的旧坐标换算规则。
