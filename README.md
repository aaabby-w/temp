# Fantasy Ring Map Template

独立的 Three.js 2.5D 环形幻想地图模板。地图使用项目所有者提供的 **8192 × 1900** 高清原图；陆地层会依据原图自动生成几何位移、凹凸与独立受光，底图、地形浮雕、网格、节点处在不同深度，不再只是单层圆柱贴图。

圆柱接缝已移动到原图约 `79%` 横向位置的连续空海域，不再强行拼接原图左右两块互不相连的大陆。这样既消除了竖直断面，也不会生成或改写任何既有地理轮廓。陆地高度遮罩使用二值化平台，不再把地区深浅配色误判成凹凸，因此原始海岸线和内部疆界只显示一次。

## 本地运行

```bash
pnpm install
pnpm dev
```

如果 `node_modules` 已经存在，不需要重复安装，直接运行 `pnpm dev`。生产构建使用：

```bash
pnpm build
```

`vite.config.ts` 使用相对路径，构建产物可以放在任意 GitHub Pages 子路径。

## 操作

- 鼠标或单指左右拖动：环向移动
- 触控板横向或纵向滑动：均转换为环向移动，不再上下移动地图
- `⌘/Ctrl + 滚轮` 或双指捏合：缩放
- `←` / `→`：环向移动；`+` / `-`：缩放；`0` / `Home`：复位
- 点击任意节点：镜头转向并打开节点面板
- 双击地图：以点击位置为中心平滑放大；再次双击返回总览

节点会在靠近时显示跟随光标的坐标提示，选中后绘制到档案面板的引导线，并按“编号 → 名称 → 坐标 → 正文”的顺序解锁内容。海岸线有低频呼吸与局部扫描光，底部状态栏会实时显示光标对应的原图坐标。开启系统“减少动态效果”时，循环扫描与过渡会停用。

为了避免把原图像素强行拉大，放大上限已经按 8192px 主图与实时渲染用途收紧。显卡支持 8192 纹理时直接使用完整原图；只有设备本身的 WebGL 上限更低时才自动降级。

## 人工添加节点（推荐）

你不必再依赖自动识别。页面里已经内置节点编辑器：

1. 启动本地页面。
2. 点击页面右下角的 `NODE EDITOR`。也可以直接在网址末尾添加 `?editNodes=1`。
3. 移动鼠标，左下角会显示当前地图原图坐标。
4. 在需要添加节点的位置单击。页面会把一整行节点代码复制到剪贴板，并短暂显示“已复制”。
5. 打开 `src/nodes.ts`，找到 `const manual: AtlasNode[] = [`。
6. 把复制的代码粘贴到数组中。例如：

```ts
const manual: AtlasNode[] = [
  { code: "U60", name: "未命名节点 60", kind: "unnamed", x: 4096, y: 950, note: "等待补充档案。" },
];
```

7. 保存文件，Vite 会自动刷新页面。需要继续添加时，请手动把后续 `code` 和名称改成 `U61`、`U62`……，避免重复编号。

如果要添加新的正式地点，把 `kind` 改成 `"named"`，并填写名称和说明：

```ts
{ code: "08", name: "新地点", kind: "named", x: 4096, y: 950, note: "这里写地点档案。" },
```

节点的 `x` 范围是 `0–8192`，`y` 范围是 `0–1900`。编辑器通过 Three.js 射线拾取读取弯曲地图表面的 UV，所以即使当前地图已经旋转，复制出来的仍然是正确的原图坐标。

## 文件位置

- 高清地图：`public/assets/fantasy-world-map.jpg`
- 节点数据与人工节点数组：`src/nodes.ts`
- Three.js 地形、镜头和交互：`src/main.ts`
- UI、节点颜色和响应式排版：`src/style.css`
- 地理与美术生产企划：`docs/world-atlas-production-plan.md`
- AI 接缝延展概念稿（未用于正式地图）：`docs/ai-seam-concept.png`

现有 7 个已命名节点为：龙游、流石、灵溪、湘竹、寒木、苍南、离岛。旧参考图中识别到的 59 个黑点仍保留为灰色未命名节点；已命名节点统一为黑色，不再使用红色。
