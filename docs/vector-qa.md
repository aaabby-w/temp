# 矢量版检查记录

检查日期：2026-10-22。矢量补绘与人工编辑工作流的发布前检查。

## 已验证

- `pnpm build` 成功；Vite 仍提示 Three.js 主包超过 500 KB，此项是体积提示而非编译错误。
- 138 个母版路径对象导出为 140 个独立色块／封闭浅色轮廓，29,496 个填色三角形；描边额外使用线段几何。
- 完整分区（包括海洋）覆盖 9216 × 1900 范围。原有 8192 × 1900 区域逐路径比较，几何保持不变；补绘增加 1024 单位宽度。
- 导出后再次验证独立面、内孔、三角形索引和邻接关系。最大三角化面积差异约 0.00874 原图像素平方，为坐标舍入误差；三角形重叠面积为 0。
- 输入 JPG 的 SHA-256 不变。运行页面未请求 JPG；地图直接加载矢量几何 JSON。
- Chrome 实际浏览器测试：1440 × 960 与 390 × 844，DPR 2，深浅模式、最大缩放、滚轮环向移动、节点切换、人工坐标编辑、减少动效模式和对照页均运行成功。控制台与资源加载未报错。
- 手机尺寸下修复了底栏挤出屏幕的问题；浏览器模拟尺寸不替代真机性能测试。
- 改用常规 MSAA 描边，避免短线段的 alpha-to-coverage 在 Retina 屏幕呈现点状断续。
- 两侧环绕截面的端点和填色匹配；实际浏览器检查了补绘海峡的深浅模式。
- `pnpm atlas:test` 验证删除孤岛、添加带曲线和变换的新岛；重复重叠路径、未闭合路径被拒绝，错误输入不替换原有网页资产。

## 仍需人工确认

这不是原始分层地图的无损复原。原始 JPEG 存在柔化线条、颜色变化和狭小轮廓；自动提取在这些位置有歧义。尤其需要检查小岛、狭长分区、近似同色区域及封闭浅色轮廓。区域 ID 是技术编号，不是国家或行政区的正式数量。

`vector-review.html` 提供原图与矢量滑动对照、25%–400% 显示和色块编号读取。报告中的分区一致率是简化前后的内部指标，不代表识别地理边界的准确率。

接缝已通过新增矢量海峡修复。新增地理仍需由设定负责人审核，不视为原作既定地图，来源与范围见 `seam-extension.md`。人工校对后用 `pnpm atlas:build` 更新网页，不重新识别 JPG。
