# 环形接缝补绘说明

本次在原始 8192 × 1900 地图的右侧新增 **1024 × 1900** 的矢量过渡区域，总画布为 **9216 × 1900**。

- 原有 x=0..8192 的色块与轮廓保持不变，自动测试逐路径比较原稿与新母版在这一区间的几何差异。
- 原图右端的浅青色陆地向新增区域自然收尾；左端两个截断的绿色地区从环绕方向延伸，形成分隔两侧陆地的海峡。
- 新增部分沿用各自相邻地区的填色。左右周期边缘在 y=186..348 与 y=438..542 的覆盖范围和颜色一致，海岸描线不会沿画布边缘多画一条直线。
- 原有节点的原图坐标保持不变；只调整含延展后的归一化投影。

**来源声明：**新增海岸是 AI 助手按接缝需求编写的矢量曲线，是艺术性补绘，不属于原始参考中已经存在的地理设定。本轮没有使用生成式图片模型，没有修改原始 JPG。它需要由世界观负责人确认后才可视为正式设定。

母版：`art-source/atlas-editable.svg`。补绘前留档：`art-source/atlas-reference.svg`。初始补绘构建记录：`scripts/prepare-editable-atlas.py`（一次性工具，会拒绝覆盖已存在的母版）。

浏览器地址末尾加 `?view=seam` 可以直接查看接缝过渡。正常进入仍从原来的核心节点开始。
